# fddpam
Fluorescent Dye Dilution Proliferation Assay Modeling

Github repository for our manuscript on mixture modeling of CFSE and CTV data. We fit mixture models to single-cell level flow cytometry data to estimate the frequency of cells in division classes. Our method takes background fluorescence into account, and can be used to jointly fit models to multiple cell types and samples.
